Optional bundled OFL Thai TrueType fonts directory for ไทยSA (`thaisa`).

Place `NotoSansThai-Regular.ttf` and `NotoSansThai-Bold.ttf` (SIL Open Font License)
here if you want identical bundled Thai typography across Windows, macOS, and Linux.
If omitted, ไทยSA automatically falls back to system Thai TrueType fonts
(`tahoma.ttf` / `leelawui.ttf` on Windows, `Thonburi.ttf` on macOS).
